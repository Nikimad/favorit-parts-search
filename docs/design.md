# Дизайн-спецификация: редизайн интерфейса

> Язык оформления: тёмная шапка-«герой» с формой и контентная область в сетке Bootstrap.
> Стили списков и карточек - стандартные компоненты Bootstrap (п. 5).

## 1. Принципы

- Только классы Bootstrap 5. Собственный CSS не нужен; если без него совсем нельзя, то не больше ~10 строк (`simplicity.mdc`).
- Меняются только JSX и классы. `src/store/`, `src/api/`, тексты и поведение из `docs/spec.md` не меняются.
- Не переносим: service worker, Sass, кастомные шрифты и иконки, анимации, модальные окна, переключатель темы.

## 2. Каркас страницы (как в источнике)

- Страница состоит из двух секций внутри `main`: тёмная шапка и контентная область. Футера нет.
- **Шапка:** `section.bg-dark` → `.container-fluid.container-xxl.py-5.px-3.px-md-5` → `.row` → `.col-md-10.col-lg-12.mx-auto.text-white`.
- **Контент:** `section.container-fluid.container-xxl.py-5.px-3.px-md-5` → `.row`.

Отклонение от источника: шапка в том же контейнере, что и контент, поэтому края формы совпадают с краями колонок; на мобильных отступ `px-3` вместо `p-5`, чтобы таблица помещалась без горизонтального скролла.

## 3. Шапка («герой»)

| Элемент | Классы (как в источнике) | Наше содержимое |
|---|---|---|
| Заголовок | `h1.display-3.mb-0` | «Подбор автозапчастей» |
| Подзаголовок | `p.lead` | «Введите артикул: покажем производителей, аналоги, цены и остатки.» |
| Форма | `form.text-body` → `.row` → `.col` + `.col-auto` | Поле и кнопка в одну строку |
| Поле | `.form-floating` → `input.form-control.w-100` + `label` | Метка «Артикул», `autoFocus`, `autoComplete="off"` |
| Кнопка | `button.h-100.btn.btn-lg.btn-primary.px-sm-5` | «Найти», `type="submit"`, отключена при пустом вводе и загрузке |
| Подсказка | `p.mt-2.mb-0.text-muted` | «Пример:» и кнопки-примеры из E-4 (`btn btn-link btn-sm p-0 align-baseline`), видна всегда |

Отклонение от источника: `text-muted` на тёмном фоне Bootstrap 5.2 малоконтрастен, поэтому подсказку делаем `text-white-50`. Синие `btn-link` на `bg-dark` дают контраст около 3,4:1, поэтому кнопкам-примерам добавлен `link-light`.
Ошибки и состояния этапа 1 остаются в колонке «Производители» (не в шапке).

## 4. Контентная область

Две колонки в одном `.row`:

| Колонка | Классы | Содержимое |
|---|---|---|
| Производители (этап 1) | `.col-md-10.col-lg-4.mx-auto` | Заголовок `h2.h4` «Производители», список, лоадер, уведомления |
| Предложения (этап 2) | `.col-md-10.col-lg-8.mx-auto` | Заголовок `h2.h4` «Предложения и аналоги», блок искомой позиции, таблица |

Заголовки колонок подчёркнуты акцентной линией цвета шапки: `pb-2.mb-3.border-bottom.border-2.border-dark`.

- На экранах ниже `lg` колонки идут столбиком: сначала производители, затем предложения.
- **Решение по умолчанию (можно поменять):** на `lg` и выше производители слева, предложения справа, чтобы сценарий читался по шагам 1 → 2. В источнике колонки зеркальны (широкая слева, узкая справа).

## 5. Применение к нашим экранам

| Экран | Решение |
|---|---|
| Список производителей | `list-group` из `list-group-item list-group-item-action`; выбранный элемент `active`. Бренд `fw-bold`, название детали `small`. |
| Блок искомой позиции | `card` → `card-body`: название, бренд и артикул, цена и остаток; бейдж «Искомая» (`badge text-bg-primary`). При `count = 0` приглушён с «Нет в наличии». |
| Таблица аналогов | `table table-hover align-middle` в `table-responsive`; шапка `table-light`; строки без наличия `text-muted`. |
| Свёртка позиций без наличия | Кнопка `btn btn-link` под таблицей, без изменений логики. |
| Пустая колонка | `p.text-muted.mb-0` с подсказкой следующего шага (`docs/spec.md`, п. 5). |
| Загрузка | `spinner-border` и подпись рядом (`text-muted`), без изменений логики. |
| Ошибка и пустой результат | `alert alert-danger` / `alert alert-info`, кнопка «Повторить» `btn btn-outline-secondary btn-sm`. |
| Мобильная версия | Поле и кнопка формы остаются в одной строке (`col` + `col-auto`); таблица прокручивается внутри `table-responsive`. Карточки вместо таблицы не делаем. |

## 7. Критерии приёмки редизайна

| ID | Проверка |
|---|---|
| AD-1 | Вверху тёмная полоса: заголовок, подзаголовок, форма «поле + кнопка» в одну строку. На ширине 360 px форма не ломается. |
| AD-2 | На `lg` и выше две колонки (производители слева), ниже `lg` один столбец. |
| AD-3 | Состояния (загрузка, пусто, ошибка с «Повторить», позиции без наличия) выглядят единообразно и читаются. |
| AD-4 | Подсказка с примерами в шапке читается на тёмном фоне. |
| AD-5 | Все критерии приёмки из `docs/spec.md` по-прежнему выполняются, `npm test` и `npm run build` проходят. |
| AD-6 | Диф не затрагивает `src/store/` и `src/api/`. Новых зависимостей нет. |
